# Código de conducta

Queremos una comunidad útil, respetuosa y segura, independientemente de la experiencia, origen, identidad o circunstancias personales de sus participantes.

- Trata a otras personas con respeto; critica propuestas y código, no a las personas.
- Da contexto, acepta correcciones y evita el acoso, insultos, amenazas y discriminación.
- No publiques información privada, credenciales ni mensajes personales sin autorización.
- No utilices el proyecto para distribuir software engañoso o eludir controles de seguridad.

El mantenedor puede pedir cambios, moderar comentarios y limitar la participación cuando sea necesario. Las decisiones deben ser proporcionales y priorizar la seguridad de las personas afectadas.

Para denunciar una conducta que implique datos privados o una vulnerabilidad, utiliza el canal privado de [SECURITY.md](SECURITY.md), no un issue público. Para otras cuestiones, contacta al mantenedor a través de su perfil público de GitHub sin exponer información personal de terceras personas.
